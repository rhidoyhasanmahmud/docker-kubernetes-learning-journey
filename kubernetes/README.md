# Kubernetes Learning Path

This section will start after the Docker foundation is complete. The examples will reuse the same Java/Spring Boot application so that the focus remains on orchestration rather than unrelated application code.

Planned progression:

1. Kubernetes architecture and reconciliation
2. Pods, ReplicaSets, and Deployments
3. Services and networking
4. ConfigMaps and Secrets
5. Probes, requests, and limits
6. Persistent storage
7. Ingress
8. Rollouts and autoscaling
9. Observability and troubleshooting
10. Helm
11. Security fundamentals
12. End-to-end Spring Boot deployment

See [ROADMAP.md](../ROADMAP.md) for learning outcomes and progress.
